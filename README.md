# 학기책 템플릿 — 내 노트가 웹이 되고, 학기 끝에 책 한 권이 된다

**이 저장소를 복사해서(위의 초록 `Use this template` 버튼) 내 노트를 쓰면**, 저장할 때마다 자동으로:

- 🌐 **웹 책(앱 한 권)** — `https://<내 아이디>.github.io/<저장소 이름>/` (휴대폰 홈 화면에 설치 가능)
- 🖨️ **인쇄본 PDF + 표지 PDF** — 인쇄소에 그대로 올리면 1부부터 제본(200쪽 흑백 1부 약 1.3만~1.6만 원)
- 📱 **전자책 EPUB**

비용: 0원(GitHub 무료) + 실물 책을 뽑을 때의 인쇄비만.

## 처음 한 번 (5분)
1. 위 **Use this template → Create a new repository** — 이름 예: `my-semester-book`, **Public** 선택(무료 GitHub Pages는 공개 저장소만 됩니다).
2. 새 저장소의 **Settings → Pages → Build and deployment → Source: GitHub Actions** 로 바꿉니다.
3. **Actions** 탭 → `책 굽기` → **Run workflow** 를 한 번 누릅니다. 2~3분 뒤 웹 책 주소가 나옵니다.

## 쓰는 법
- `notes/book.json` — 제목 · 지은이 · 판형(A5 · B6 · 신국판 · 46판 …).
- `notes/00.md`, `01.md` … — `# 제목` 한 줄 = 장 하나. 휴대폰에서도 GitHub 앱 · 웹에서 바로 고칠 수 있습니다.
- 특별 블록: `:::용어` (눌러 보는 카드) · `:::퀴즈` (눌러서 정답) · `:::비교` (표) — 인쇄본에서는 상자 · 표가 됩니다.

## 책으로 뽑기
- 웹 책 표지의 **인쇄본 PDF** · **전자책** 버튼, 또는 Actions 실행 결과의 `print-pack`(인쇄소에 올릴 두 파일).
- 인쇄소에 `interior.pdf`(내지) + `cover.pdf`(표지)를 올리고 부수 · 종이 · 무선 제본을 고릅니다.
- 개인 소장 · 과제용이면 **ISBN 없이** 됩니다. 서점 판매만 ISBN이 필요합니다.

## 저작권 한 장
내 말로 정리한 내용이 주인공, 원문은 꼭 필요한 문장만 `>` 인용 + 출처(저자 · 책 · 쪽). 그림 · 표는 다시 그리고 "○○ p.32 재구성". 교재 통째 · 연습문제 해설 · 강의 슬라이드를 그대로 옮기지 않습니다.
